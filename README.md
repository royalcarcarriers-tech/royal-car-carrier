# Royal Car Carrier Website

Professional one-page static website for Royal Car Carrier LLC.

## Files

- `index.html` — website structure and content
- `style.css` — full responsive design
- `script.js` — mobile navigation and quote-form demo behavior

## Publish with GitHub Pages

1. Create a new GitHub repository, for example:
   `royal-car-carrier`

2. Upload `index.html`, `style.css`, and `script.js` to the root of the repository.

3. In GitHub open:
   **Settings → Pages**

4. Under **Build and deployment** choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`

5. Click **Save**.

GitHub will provide a Pages URL such as:
`https://YOUR-USERNAME.github.io/royal-car-carrier/`

## Before final launch

Replace the placeholder contact information with:
- Business phone
- Final business email
- USDOT number
- MC number if applicable
- Business mailing address if desired

The quote form is currently visual only. It can be connected to Formspree, EmailJS, Google Forms, or a CRM.
